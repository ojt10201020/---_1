1. 백업 파일 선택

이전 전 확인해 주세요

파일 선택과 미리보기는 읽기만 수행합니다. Supabase 인증·업로드·게시물 등록은 아래의 이전 시작 버튼을 누른 경우에만 진행됩니다.

원본 작성자의 Supabase 사용자 ID는 백업에 없으므로, 이전된 게시물은 이번 도구에서 사용하는 익명 인증 계정이 소유합니다. 게시물에 표시되는 기존 닉네임은 유지됩니다. 기존 댓글은 작성자 연결이 불가능해 이전하지 않고, 기존 공감 수만으로 사용자별 공감 기록을 만들지 않습니다.
